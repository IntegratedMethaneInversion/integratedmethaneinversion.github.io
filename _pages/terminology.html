Terminology

We define here common technical terms used in the IMI documentation. For an introductory textbook description of inverse methods using the IMI terminology, see Chapter 11: Inverse Methods for Atmospheric Chemistry, in Modeling of Atmospheric Chemistry by G.P. Brasseur and D.J. Jacob, Cambridge University Press, 2017.

Averaging kernel sensitivity

Estimates how sensitive the posterior solution for a given state vector (emission) element is to observations as opposed to the prior estimate. An emission element with averaging kernel sensitivity 0 is not quantified by the observations at all, and the inversion returns the prior value for that element. An emission element with averaging kernel sensitivity 1 is fully quantified by the observations, and the inversion results for that element are independent of the prior estimate.

Boundary Conditions

3D time-depenent methane concentration fields applied at the edges of the inversion domain. They are from a global GEOS-Chem simulation for the period of interest locally corrected with smoothed observations from the satellite instrument used in the inversion. See Estrada et al. (2025) for details. The mean boundary conditions along the four cardinal edges can be included in the state vector to be optimized by the inversion.
